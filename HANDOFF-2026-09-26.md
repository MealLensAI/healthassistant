The intended integration is:

| Concern | Intended location |
| --- | --- |
| Original account identity/passwords | Existing Supabase Auth |
| Original subscriptions/payments | Existing application billing/Paystack tables |
| Marketplace records | Supabase `mp_*` tables |
| Images/documents/attachments | Cloudflare R2 |
| Object keys, ownership and metadata | Supabase |

Do not confuse this intended architecture with a completed security/persistence audit. Care endpoints still rely on `X-User-Id` in several paths; sync accepts body identity fields. ## Additional implementation details from read-only code audit

### Calls, ringtone and popup

- `ringtone.ts` manages reusable Web Audio context and gesture unlock, pulses at 440/480 Hz, repeats around every 2400 ms, and stops/disposes timers/oscillators.
- `IncomingCall.tsx` offers an enable-sound control if autoplay is blocked and answers only after media acquisition succeeds; the old `finally`-based answer path could answer after acquisition failure.
- `callMedia.tsx` centralizes remote audio, enumerates devices, listens for device changes, replaces active tracks, preserves mute/camera state, falls back to audio if camera fails, avoids overlapping signaling polls and cleans up peer/media resources.
- `VideoStage.tsx` mutes remote video because the central audio element handles sound; provides explicit playback unblock, mic/camera controls and audio-only presentation.
- `CallWindow.tsx` uses a React portal into a named `meallens-consultation` popup, copies styles/theme, keeps the same peer/media provider, closes with the call, and falls back to an in-app overlay if the popup is blocked or closed.
- Deployment configuration discussed: `VITE_TURN_URL`, `VITE_TURN_USERNAME`, `VITE_TURN_CREDENTIAL`. Values are not included. Default STUN cannot replace a relay on restrictive networks.
- Do not promise ringtone before any user interaction, physical audio quality or cross-network success from simulated tests.

### Attachments, applications and files

- Chat upload stores `objectKey`, `bucket`, MIME/type and size metadata. `SEND_MESSAGE` validates conversation membership, uses actor identity and creates the associated shared health-file record with the message state change.
- `CarePage.tsx` and `MessagesPage.tsx` await send and keep unsent content on failure; file selection/sending uses busy state. CarePage consumes `call=1` before call initiation to avoid repeated starts.
- `useAttachmentUrl.ts` turns supported legacy data URLs into revocable blob URLs for preview/download. It supports PDF/plain-text/image preview types; other content is treated as octet-stream.
- `ApplyPage.tsx` uploads the photo to avatar storage, credentials to private storage, marks uploaded only after response, and awaits application save before leaving editing mode.
- Server `SUBMIT_APPLICATION` uses the actor's ID, a server UUID and pending status/submission time; resubmission retains the prior application's ID/admin notes. Administrative approval updates listing status.
- Application-document metadata held only for newly uploaded files and initialization before async state arrives require testing so editing does not erase existing references.
- `FilesPage.tsx` metadata save remains fire-and-forget through context dispatch; it can still show success before server persistence. Do not generalize the awaited patient photo fix to every uploader.
- `DietitianProfilePage.tsx` owner's avatar handler does not await `saveAccount` before local metadata updates, unlike the revised `DietitianAccountPage.tsx`. This is another path to verify.

    def persist_account_update(self, state: Json, user_id: str) -> None:
        """Write only this account's profile (+ listing if present). Avoids full-state replace."""
        if not _UUID_RE.match(str(user_id)):
            raise ValueError('A valid account ID is required')
        user = next((item for item in state.get('users', []) if item.get('id') == user_id), None)
        if not user:
            raise ValueError('Unknown account')
        self.client.table(MP_TABLES['profiles']).upsert(profile_row(user), on_conflict='id').execute()
        listing = next((item for item in state.get('dietitians', []) if item.get('userId') == user_id), None)
        if listing and _UUID_RE.match(str(listing.get('id', ''))):
            self.client.table(MP_TABLES['dietitians']).upsert(dietitian_row(listing), on_conflict='id').execute()

def sync_account_endpoint():
    body = _json()
    # Accept camelCase from frontend or snake_case
    payload = {
        "avatar": body.get("avatar") or "",
        "externalUserId": body.get("externalUserId") or body.get("external_user_id") or "",
        "email": body.get("email") or "",
        "name": body.get("name") or "",
        "phone": body.get("phone") or "",
        "country": body.get("country") or "",
        "role": body.get("role") or "patient",
    }
    try:
        store = get_store()
        if hasattr(store, 'sync_user'):
            user = store.sync_user(payload)
        else:
            next_state, user = sync_account(store.snapshot(), payload)
            store.replace(next_state)
    except ValueError as error:
        return jsonify({"detail": str(error)}), 400
    except Exception as error:
        current_app.logger.error('Care account sync failed (%s, code=%s)', type(error).__name__, getattr(error, 'code', 'unknown'))
        return jsonify({"detail": "Your profile could not be synced. Please retry shortly."}), 503
    return jsonify({"user": user, "token": user["id"]})

import type { Dietitian, DietitianApplication, User } from './types'

/** Older registrations saved the photo on the listing, not the account. */
export function accountAvatar(
  user: User | null | undefined,
  dietitians: Dietitian[],
  applications: DietitianApplication[] = [],
): string {
  if (!user) return ''
  if (user.avatar) return user.avatar
  if (user.role !== 'dietitian') return ''
  return dietitians.find((item) => item.userId === user.id)?.avatar
    || applications.find((item) => item.userId === user.id)?.documents.find((document) => document.kind === 'photo' && document.url)?.url
    || ''
}

  }
